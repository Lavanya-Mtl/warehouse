## Learning from this project

This project taught me that building a complete Django app is about making smart trade-offs. The box recommendation algorithm went from a complex 3D bin-packing idea to a simple bounding-box approach - it's fast, explainable, and works perfectly for the warehouse team's needs.

Working with AI tools was a mixed bag. They're great for boilerplate, but I had to review and fix plenty of mistakes - directory structures, database choices, and Django conventions that the AI got wrong.

Setting up the test suite with GitHub Actions was very satisfying and cool. Automated tests on every push gave me confidence to refactor without breaking things.

Overall it was a great learning experience to develop a django app using AI for the first time. I believe much of basic web development is automatable giving the developer more time to concentrate on important features, security and reliability of a system. This project could have taken much longer otherwise.
